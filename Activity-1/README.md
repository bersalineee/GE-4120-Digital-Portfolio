## ✨ Description

In this activity, we were tasked with designing a **Free Coffee** promotional poster while applying the four basic presentation design principles: **Contrast, Repetition, Alignment, and Proximity**. By using these principles, I created a poster with a clear layout, consistent design, readable text, and visually balanced elements to effectively communicate the event information.

---

## 💡 What Have I Learned?

- 💜 I learned how to apply the four basic presentation design principles: Contrast, Repetition, Alignment, and Proximity.
- 🎨 I discovered how colors, typography, and visual elements can make a promotional poster more attractive and engaging.
- 🌷 One challenge I faced was organizing the poster elements to maintain visual balance and readability. I addressed this by carefully arranging the text, graphics, and event details.
- ✨ I learned the importance of consistency and proper spacing in creating an effective presentation design.
- 🚀 In the future, I can apply these skills to create visually appealing posters, presentations, infographics, and other digital materials.
