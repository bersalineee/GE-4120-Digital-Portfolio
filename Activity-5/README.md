## ✨ Description

This activity focused on using **ChatGPT as an AI tool to generate images through text prompts**. I experimented with two different prompts to create images of houses. The first prompt was simple, while the second included more specific details about my dream house, such as its design, roof, gate, garage, cars, swimming pool, and garden.

Through this activity, I explored how AI tools can transform written descriptions into visual outputs and how detailed instructions can produce more personalized results.

---

## 💡 What Have I Learned?

- 💜 I learned how to use ChatGPT to generate images using text prompts.
- 🎨 I discovered that clear and detailed instructions produce better and more personalized results.
- 🌷 One challenge I faced was making the generated image match my preferred dream house design. I solved this by adding more specific descriptions and features to my second prompt.
- ✨ I learned the importance of creativity and effective prompt writing when using AI tools.
- 🚀 In the future, I can apply these skills to create visual content for presentations, digital portfolios, and other creative projects.
