# Activity 3: Social Media Infographics and Mini Project Documentation

## Description

In this activity, we were tasked with creating a **one-page infographic** and a **mini project documentation report** based on a real-world problem. My chosen topic is **Cyberbullying**, where I designed an infographic to raise awareness and proposed **Project SPEAK**, a school-based cyberbullying reporting and monitoring system, as a technology-enabled solution. This activity strengthened my skills in information synthesis, visual storytelling, infographic design, and project documentation while applying effective communication and problem-solving techniques.
