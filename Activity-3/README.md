## ✨ Description

In this activity, we were tasked with creating a **one-page infographic** and a **mini project documentation report** based on a real-world problem. My chosen topic is **Cyberbullying**, where I designed an infographic to raise awareness and proposed **Project SPEAK**, a school-based cyberbullying reporting and monitoring system, as a technology-enabled solution. This activity strengthened my skills in information synthesis, visual storytelling, infographic design, and project documentation while applying effective communication and problem-solving techniques.

---

## 💡 What Have I Learned?

- 💜 I learned how to create an informative infographic that raises awareness about cyberbullying and its effects on students.
- 🎨 I developed my skills in visual storytelling, layout design, typography, and organizing information into an engaging and understandable format.
- 🌷 One challenge I faced was presenting complex information about cyberbullying in a one-page infographic. I addressed this by organizing the content into clear sections and using visual elements to improve readability.
- ✨ I learned how to develop a technology-based solution through project documentation by proposing Project SPEAK, which integrates reporting, monitoring, and digital citizenship education.
- 🚀 In the future, I can apply these skills to create awareness campaigns, educational infographics, and technology-based solutions for real-world problems.
